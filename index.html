Menggabungkan Desain & Logika Menjadi Kode Nyata

Perjalanan saya di dunia pemrograman dimulai dari ketertarikan mendalam pada bagaimana elemen visual di internet dibuat dan berinteraksi. Sebagai seorang Frontend Developer, misi saya adalah memberikan pengalaman pengguna terbaik melalui antarmuka web yang bersih, cepat, dan intuitif.

Saya sangat menyukai kesederhanaan dalam struktur HTML serta kedahsyatan Tailwind CSS yang memungkinkan gaya visual yang stylish tanpa menambah beban performa situs. Saya selalu antusias untuk mempelajari hal-hal baru dan terus meningkatkan keahlian koding saya.
